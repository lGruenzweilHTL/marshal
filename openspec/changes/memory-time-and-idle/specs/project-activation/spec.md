## ADDED Requirements

### Requirement: Project summaries
Each project SHALL have an optional summary (at most 120 words, English) with its update time, generated by the idle-time jobs from the project's open chunks and the project description. For every project that is active in a turn, the summary SHALL be added to the context. The memory view SHALL show the summary read-only with its update time.

#### Scenario: Summary in context
- **WHEN** project "Voron" is active in a turn and has a summary
- **THEN** the system prompt contains the summary in the project section

#### Scenario: No summary yet
- **WHEN** an active project has no summary
- **THEN** the turn proceeds without it
