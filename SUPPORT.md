# Getting support

Where to find help with Marshal.

## Before you ask

1. Check the [FAQ](docs/faq.md) and the [troubleshooting guide](docs/guides/troubleshooting.md).
2. If Marshal does not start, run `docker compose logs marshal`. Startup lists every configuration problem with its file and key.
3. Search existing issues.

## Questions and problems

Open an issue in the repository and pick the matching form: [bug report](.github/ISSUE_TEMPLATE/bug_report.yml) or [feature request](.github/ISSUE_TEMPLATE/feature_request.yml). Include your Marshal version or commit, how you run it, and relevant log lines. Remove secrets and personal data first.

## Security problems

Do not use public issues. Follow the [security policy](SECURITY.md).

## What to expect

Marshal is maintained by one person in spare time and has no release yet. There is no guaranteed response time and no commercial support.
